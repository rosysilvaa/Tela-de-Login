# 💻 Tela de Login Minimalista e Moderna

Uma página de login elegante e responsiva desenvolvida **apenas com HTML5 e CSS3**, com foco em um design limpo, centralizado e um efeito visual marcante de gradiente no fundo.

---

## 🎨 Destaque do Design: O Background

O grande diferencial estético deste projeto é o seu fundo imersivo, criado através da propriedade `background` com um gradiente linear em um ângulo de 45 graus.
